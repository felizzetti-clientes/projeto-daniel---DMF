# DMF Intelligent Systems — site institucional

Next.js (App Router) · TypeScript · Tailwind v4 · Motion · Lucide.

    npm install
    cp .env.example .env.local   # preencher domínio, WhatsApp e Resend
    npm run dev                  # desenvolvimento
    npm run build && npm start   # produção

Pendências para publicar: definir `NEXT_PUBLIC_SITE_URL` (domínio oficial), `NEXT_PUBLIC_WHATSAPP` e as variáveis do Resend (formulário).
Novas demonstrações: adicionar um item em `lib/demos.ts`. Novas soluções: `lib/solutions.ts`.
